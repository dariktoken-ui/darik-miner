# داریک ماینر — نسخه آزمایشی

این مخزن رابط کاربری Mini App تلگرام داریک ماینر را نگه می‌دارد.

## وضعیت
- اتصال رابط کاربری به Supabase Edge Function با Telegram WebApp initData
- دریافت پروفایل و مأموریت‌ها از `bootstrap`
- ارسال مأموریت با `submit_quest`
- پاداش واقعی DRK غیرفعال است؛ امتیازها صرفاً آزمایشی‌اند.

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: ظاهر واکنش‌گرا با تم مشکی و طلایی
- `app.js`: ارتباط با API

## اجرای محلی
برای آزمایش واقعی، برنامه باید از یک نشانی HTTPS و از داخل ربات تلگرام باز شود. باز کردن مستقیم فایل در مرورگر، Telegram initData معتبر تولید نمی‌کند.

ربات: https://t.me/DarikQuestBot

**هشدار:** توکن ربات یا کلیدهای محرمانه Supabase را هرگز در فایل‌های frontend قرار ندهید.
